Política de Privacidade

Última atualização: Setembro de 2026

A proteção da privacidade e dos dados dos nossos usuários é um pilar central do Projeto UTOME, especialmente por lidarmos com tecnologia assistiva para crianças com Transtorno do Espectro Autista (TEA).

1. O Nosso Compromisso com a Privacidade

O UTOME foi projetado com foco no baixo estímulo e na previsibilidade. Esse princípio se estende à captação de dados:

  • Não possui microfones para gravação de voz contínua.
  • Não possui câmeras ou sensores de imagem.
  • Não rastreamos a localização GPS do dispositivo.
  • Suas funções básicas operam offline.

2. Dados Coletados

Coletamos apenas os dados necessários para o funcionamento do sistema:

  • Dados do Responsável (Plataforma Web): Nome, e-mail e dados de autenticação (Firebase Auth).
  • Dados do Dispositivo (UTOME): Bateria, conectividade, ID do Dispositivo (device_id) e o histórico de rotinas (quando a criança confirmou uma tarefa no sensor TTP223).

3. Uso e Armazenamento dos Dados

Os dados são armazenados de forma segura na infraestrutura do Google Firebase, sendo encriptados em trânsito (HTTPS) e em repouso. Eles são utilizados exclusivamente para permitir que o Responsável acompanhe as rotinas no painel.

4. Compartilhamento de Dados

Nós não vendemos, alugamos ou compartilhamos os dados pessoais dos responsáveis ou os dados de rotina das crianças com terceiros, anunciantes ou empresas de marketing.

5. Proteção à Privacidade Infantil (LGPD/COPPA)

O UTOME não se comunica diretamente com a criança via internet aberta, nem solicita dados da criança. A criação da conta, a definição das tarefas e o monitoramento são feitos exclusivamente pelo Responsável Legal.
